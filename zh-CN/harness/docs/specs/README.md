# 需求与验收

新功能和功能增强由主 agent 按 [feature-plan](../../.agents/skills/feature-plan/SKILL.md) 访谈并同步整理规格书，使用 [模板](TEMPLATE.md)。每个功能保存为 `PLAN-0001.md`，与计划共用功能编号；小功能使用短规格，普通问答和按既有契约修复缺陷不强制新增规格书。

规格书记录要做什么、行为边界及 AC-01 形式的验收场景；实现步骤、派工与进度只保存在关联计划。两份文档分别版本化，一起展示给用户确认，批准依据由计划统一保存。回答某个访谈问题不等于批准整套方案。

计划完成或取消后移至 plans/completed，规格书保留原位并同步状态和链接，不为每轮讨论或归档复制规格书。
