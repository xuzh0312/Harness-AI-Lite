# 子任务交接模板

本文件供主 agent 填写后作为提示发送，不作为自动配置。删去说明文字并填入实际路径及配置；输入不足时不要发起有依赖的实现。

```text
任务编号：<主任务 ID / 子任务 ID>
角色：<UIdesign / implementer / reviewer>
审查实例与维度：<reviewer-spec／规格符合性，或 reviewer-quality／实现质量；其他角色注明不适用>
审查组与轮次：<任务项或整体审查标识、轮次及同组另一实例；非审查任务注明不适用>
目标与非目标：<具体说明>
Harness 绝对路径：<路径>
Project 绝对路径：<路径；不使用时说明>
Test 绝对路径：<路径；不使用时说明>
工作目录：<实际绝对路径>
必读材料：<Harness AGENTS.md、agents/MODELS.md、角色共享协议、角色说明、目标目录规则、需求与计划>
功能任务批准组合：<规格书路径与版本、计划路径与版本、相关验收编号；规划访谈中注明草案与待确认项；独立设计或直接修改时注明不适用>
执行阶段与简报：<需求梳理／界面细化／初次实现／返工／逐项审查／整体审查；已有计划时给出简报定位>
输入与基线：<代码提交及已有工作树改动，或受审文件范围；数据版本；界面项附已确认稿件和关键状态>
允许读取／修改范围：<具体路径；只读时明确>
已有改动与其他执行者：<需保留内容、冲突边界>
前置依赖：<已满足的输入或尚未满足的条件>
验收标准：<可观察结果>
验证方式与证据位置：<命令、工作目录或人工检查方式>
reviewer 输入与输出：<两实例共用的受审版本、完整任务差异及前置基线、要求来源、执行报告和证据；本实例独立返回所负责维度结论>
权限边界：<是否有明确的提交、推送等授权；未授权不执行>
配置来源：<Harness agents/MODELS.md 实际绝对路径>
DSH 子 agent 设置：inherited；省略 provider、model 和 reasoning_effort

遵守共享协议，按统一格式返回；不更新主任务状态，不嵌套创建 agent。
最终回复必须以如下配置行结尾，包括受阻或失败回复。
仅在运行器提供实际设置时报告其值；若运行器报告不一致的设置或被禁用的路由，停止并报告。
模型选择：<运行器报告的 provider/model 或 inherited (not independently verified)>；推理深度：<运行器报告的推理深度或 inherited (not independently verified)>
```

发送前，主 agent 必须重读 MODELS.md，在配置页脚填入运行器报告值，未提供的字段填 `inherited (not independently verified)`，并将页脚放在提示的最后一行。子 agent 仅在运行器提供更精确的设置时更新页脚。
