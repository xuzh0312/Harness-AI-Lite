# UI 技法图鉴

解压后保留原目录结构，直接用现代浏览器打开 [布局图鉴](<布局图鉴.html>) 或 [动效与材质图鉴](<动效与材质图鉴.html>)。无需安装、构建或启动服务。

- 首页先展示容易混淆的对照。点「查全部编号」进入完整目录，可用章节链接跳转，或用搜索框输入编号及中英文术语。
- 目录中的「已有对照」跳到对应卡片；其余条目展开才运行示例，收起则重置。布局页的「宽容器 / 窄容器」同时控制对照和目录预览宽度。
- 每个示例的源码对应正在运行的效果。「近似」只复现特征；「示意」说明流程，不等同于原生系统、设备或模型已经接入。
- 给 Agent：先按术语找到标本，比较操作前后或宽窄变化，再看源码。复用决定效果的那部分，不照搬演示内容或配色。

覆盖口径：[布局分类参考](<页面布局设计全景分类参考.md>) 48 项、[动效与风格分类参考](<动效界面设计风格全景分类参考.md>) 68 项，按编号分别覆盖；两份参考之间有重叠，116 个编号不等于 116 种互不重复的技法。资源表与技术附录不单独做标本。
