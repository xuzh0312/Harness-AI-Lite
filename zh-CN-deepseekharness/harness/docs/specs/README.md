# 需求与验收

用户选择功能规划时，主 agent 用 [feature-plan](../../.agents/skills/feature-plan/SKILL.md) 访谈用户，并按[模板](TEMPLATE.md)维护规格书。每份规格书保存为 `PLAN-0001.md` 这类文件，与计划共用功能编号。小功能可写简短规格。普通问答和遵照现有契约的缺陷修复不需要新建规格书。

规格书记录要做什么、行为边界及形如 `AC-01` 的验收场景；实现步骤、分派和进度只记在关联计划里。两份文档分别版本化，一同提交用户确认；确认依据统一保存在计划里。回答单个访谈问题不等于批准整个方案。

计划完成或取消后移至 `plans/completed`；规格书留在原处，并更新状态和链接。不为每轮讨论或每次归档复制规格书。
