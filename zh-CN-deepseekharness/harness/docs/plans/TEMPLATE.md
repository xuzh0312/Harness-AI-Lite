- 分派基线：相关仓库、提交及已有未提交改动的边界；不使用 Git 时，记录文件快照或内容比对基线。
- 交付：实际文件与结构变更、自查结果、检查证据、未完成事项和执行者标识。
- 审查材料：完整任务改动范围、简报、执行报告及证据；原始 diff 或快照在 `test` 中的位置。
- 独立结论：reviewer-spec 和 reviewer-quality 各自的报告、实例标识与分配的维度、两者共同审查的版本、实际并行或顺序审查情况，以及问题、裁定、返工轮次与验证结果。
