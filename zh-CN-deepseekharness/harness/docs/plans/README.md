# 执行计划

待确认和执行中的计划放在 `active`，已完成或已取消的计划归档至 `completed`。复杂任务使用模板。选择直接修改的功能任务不需要新建计划。

用户选择功能规划时，调用 [feature-plan](../../.agents/skills/feature-plan/SKILL.md)。主 agent 逐次只向用户提一个问题，同时维护 `specs` 中的规格书，自动分配形如 `PLAN-0001` 的共用编号，再生成详细的功能实现清单。规格书与计划分别版本化，并一同提交用户确认。局部回答不代表确认当前组合。待确认的计划留在 `active`；确认后在原文件跟踪执行，完成后移至 `completed`。取消的计划应先标为已取消再归档，如实反映实施状态。规格书留在 `specs`，归档时同步两份文档的链接。

每个项目独立编号。修订或续接沿用原计划；实质变更的文档须提高版本号，并重新确认组合。实现清单项使用形如 `PLAN-0001.01` 的稳定编号，并引用规格书的验收编号。确认依据、逐项简报、交付摘要、审查和续接入口统一保存在原计划，不重复创建进度记录。
