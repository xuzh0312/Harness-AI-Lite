# 动画术语

把对运动或效果的模糊描述转换为准确术语，让用户知道应该如何提出需求。

## 快速开始

用户只是宽泛地描述一个效果时，按以下格式返回匹配的术语：

```
**Stagger（错开）** — 让多个项目依次出现，每项之间保留短暂延迟，形成级联效果。
```

如果多个术语都可能适用，先列出最匹配的术语，再列出 1–2 个备选，并用一句话说明它们之间的区别。

## 使用说明

1. **理解意图，不要只抓关键词。** 用户描述的是自己*看到*或*感受到*的效果（“有弹性”“滑出去”“自己画出来”），而不是技术名称。要把这种感觉对应到下面的术语表中。
2. **按术语表中的描述说明。** 术语表里的描述是权威依据，应保持原意，不要臆造或改变其含义。
3. **区分相近术语。** 两个术语都可能适用时（*Clip-path* 与 *Mask*、*Pop in* 与 *Bounce*、*Shared element transition* 与 *Layout animation*），说明差异，方便用户选择。
4. **没有完全匹配的术语时，** 给出最接近的术语并明确说明这只是近似；也可以使用术语表中的词来描述该效果（例如“这是由 *scale-in* 入场组成的 *stagger*”）。
5. **只使用本术语表。** 如果某个术语确实不在这里，直接说明，不要自创术语；但可以使用这里的词解释相关概念。
6. **保持简洁。** 命名问题需要的是名称，不是长篇说明。先给术语；只有用户追问时再展开。

## 示例

**示例 1 — 根据感觉描述**

用户：“浮层好像是从点击的按钮那里长出来的，而不是从中间出现，这个效果叫什么？”

输出：

```
**Origin-aware animation（感知原点动画）** — 元素从触发它的控件位置开始动画，例如浮层从打开它的按钮处展开，而不是从自身中心展开；从自身中心展开是 CSS 的默认行为。
```

**示例 2 — 区分相近术语**

用户：“一张图片变成另一张图片的那个效果。”

输出：

```
**Morph（形变）** — 一种形状平滑地变成另一种形状，例如 Dynamic Island。

接近的备选：
- **Crossfade（交叉淡化）** — 两张图片只是位于同一位置并相互淡入淡出。
- **Shared element transition（共享元素过渡）** — 一个元素从一个位置移动并变换到另一个位置。
```

**示例 3 — 描述物理感觉**

用户：“iOS 里滚动拉得太远时会顶住，然后弹回去的那个效果。”

输出：

```
**Rubber-banding（橡皮筋回弹）** — 拖动越过边界时产生阻力，松手后回弹（即 iOS 过度滚动的手感）。
```

## 术语表

_这是项目 `/vocabulary` 页面的人工整理快照；任意一方变更时，应同步更新两边。_

### 入场与退场 — 元素如何出现和消失

- **Fade in / Fade out（淡入／淡出）** — 元素通过改变不透明度出现或消失。
- **Slide in（滑入）** — 元素从屏幕外（左、右、上或下）滑入。
- **Scale in（缩放进入）** — 元素出现时由较小尺寸增长到完整尺寸，通常与淡入搭配。
- **Pop in（弹入）** — 元素出现时略微越过目标尺寸，像弹跳到最终位置。
- **Reveal（揭示）** — 内容逐渐显露，通常通过给 clip-path 或遮罩添加动画实现。
- **Enter / Exit（入场／退场）** — 元素被添加到屏幕或从屏幕移除时播放的动画。

### 编排与时间 — 协调多个元素或多个时刻

- **Keyframes（关键帧）** — 动画中预先定义的时间点（0%、50%、100%），浏览器负责填充这些点之间的帧。
- **Interpolation / Tween（插值／补间）** — 在起始值和结束值之间生成所有中间帧，使运动保持连续。
- **Stagger（错开）** — 让多个项目依次出现，每项之间保留短暂延迟，形成级联效果。
- **Orchestration（编排）** — 有意识地安排多个动画的时间关系，使它们看起来像一段协调统一的运动。
- **Delay（延迟）** — 动画开始前的等待时间。
- **Duration（时长）** — 动画从开始到结束所需的时间。
- **Fill mode（填充模式）** — 动画开始前或结束后，元素是否保留第一帧或最后一帧的样式（例如 forwards）。
- **Stepped animation（分步动画）** — 分成离散步骤播放的动画，例如倒计时。

### 运动与变换 — 改变元素的位置、尺寸或角度

- **Translate（平移）** — 沿 X 轴或 Y 轴移动元素。
- **Scale（缩放）** — 放大或缩小元素。
- **Rotate（旋转）** — 围绕一个点旋转元素。
- **Skew（倾斜）** — 沿 X 轴或 Y 轴斜切元素，使其偏离原来的矩形形状。
- **3D tilt / Flip（3D 倾斜／翻转）** — 在三维空间中旋转（rotateX / rotateY），增加纵深感。
- **Perspective（透视）** — 3D 效果的强弱——数值越低，纵深感越夸张，仿佛观察者离得更近。
- **Transform origin（变换原点）** — 缩放或旋转所围绕的锚点。
- **Origin-aware animation（感知原点动画）** — 元素从触发它的控件位置开始动画，例如浮层从打开它的按钮处展开，而不是从自身中心展开；从自身中心展开是 CSS 的默认行为。

### 状态之间的过渡 — 把一个状态、视图或元素连接到另一个

- **Crossfade（交叉淡化）** — 一个元素在同一位置淡出，另一个元素同时淡入。
- **Continuity transition（连续性过渡）** — 在视觉上连接变化前后的内容，帮助用户保持方向感。例如让同一个矩形放大或缩小。
- **Morph（形变）** — 一种形状平滑地变成另一种形状，例如 Dynamic Island。
- **Shared element transition（共享元素过渡）** — 一个元素从一个位置移动并变换到另一个位置，例如缩略图展开成卡片。
- **Layout animation（布局动画）** — 元素的尺寸或位置发生变化时，动画移动到新位置，而不是瞬间跳过去。
- **Accordion / Collapse（手风琴／折叠）** — 一个区域平滑展开或收起高度，以显示或隐藏内容。
- **Direction-aware transition（方向感知过渡）** — 前进时内容朝一个方向滑动，返回时朝相反方向滑动，使导航具有方向感。

### 滚动 — 与滚动或视图导航关联的运动

- **Scroll reveal（滚动揭示）** — 元素进入视口时淡入或滑入到目标位置。
- **Scroll-driven animation（滚动驱动动画）** — 动画进度直接绑定滚动位置。
- **Parallax（视差）** — 滚动时背景和前景以不同速度移动，形成纵深感。
- **Page transition（页面过渡）** — 从一个页面或路由导航到另一个页面时播放的动画。
- **View transition（视图过渡）** — 浏览器在两个状态或页面之间执行形变，并连接共享元素。

### 反馈与交互 — 对用户的操作做出回应

- **Hover effect（悬停效果）** — 指针移到元素上时发生的视觉变化。
- **Press / Tap feedback（按压／点按反馈）** — 元素被点击时轻微缩小，使其具有物理触感。
- **Hold to confirm（长按确认）** — 用户按住按钮期间，进度效果逐渐填满。
- **Drag（拖动）** — 抓住并移动元素，松开时通常带有惯性。
- **Drag to reorder（拖动排序）** — 拖动列表中的项目重新排列，其他项目让出空间并移动。
- **Swipe to dismiss（滑动关闭）** — 将元素拖出屏幕来关闭它，例如抽屉或提示消息。
- **Rubber-banding（橡皮筋回弹）** — 拖动越过边界时产生阻力，松手后回弹（即 iOS 过度滚动的手感）。
- **Shake / Wiggle（抖动／摇晃）** — 快速左右抖动，用于表示错误或输入被拒绝。
- **Ripple（涟漪）** — 从点按位置向外扩散的圆环，用于确认按压。

### 缓动 — 动画速度如何变化

- **Easing（缓动）** — 动画加速或减速的速率。
- **Ease-out（缓出）** — 开始快、结束慢。大多数 UI 动画和所有对用户作出响应的动画的默认选择。
- **Ease-in（缓入）** — 开始慢、结束快。通常应避免，因为它可能让人感觉迟缓。
- **Ease-in-out（缓入缓出）** — 慢、快、慢。适合已经在屏幕上、从 A 点移动到 B 点的元素。
- **Linear（线性）** — 匀速。UI 中应避免使用；可留给加载旋转指示器或跑马灯。
- **Cubic-bezier（三次贝塞尔曲线）** — 为实现精确控制而自定义的缓动曲线。
- **Asymmetric easing（非对称缓动）** — 加速和减速速率不同的曲线。比对称曲线更有生命力。

### 弹簧动画 — 用基于物理的运动替代固定时长缓动

- **Spring（弹簧）** — 由物理参数（张力、质量、阻尼）驱动，而不是由固定时长驱动。
- **Stiffness / Tension（刚度／张力）** — 弹簧拉向目标位置的强度。数值越高，感觉越干脆。
- **Damping（阻尼）** — 弹簧停下来的速度。阻尼越低，来回弹动和振荡越明显。
- **Mass（质量）** — 动画元素感觉有多重。质量越大，运动越慢、越迟滞。
- **Bounce（回弹）** — 弹簧越过目标位置后回落，增加活泼感。
- **Perceptual duration（感知时长）** — 弹簧在感觉上完成运动所需的时间，即使它在底层仍持续进行细微沉降。
- **Momentum（惯性）** — 携带速度的运动，特别是在拖动或中断之后。
- **Velocity（速度）** — 元素运动的速度和方向。被中断时，弹簧会把它带入下一段动画，因此被快速甩出的元素会保留速度。
- **Interruptible animation（可中断动画）** — 可以在运动途中平滑改变目标，而不是必须先播放完毕的动画。

### 循环与环境运动 — 自行播放的动画

- **Marquee（跑马灯）** — 文本或内容以循环方式持续滚动。
- **Loop（循环）** — 按指定次数或无限次重复的动画。
- **Alternate (yoyo)（交替／往复）** — 每轮先正向播放再反向播放，而不是直接跳回起点。
- **Orbit（环绕）** — 一个元素沿着连续轨迹围绕另一个元素运动。
- **Pulse（脉冲）** — 轻微重复的缩放或不透明度变化，用于吸引注意。
- **Float（漂浮）** — 轻柔、连续地上下漂移，让静止元素显得有生命、没有重量。
- **Idle animation（待机动画）** — 元素静止等待交互时播放的细微运动。

### 细节与效果 — 区分优秀与卓越的小处理

- **Blur（模糊）** — 用模糊滤镜软化元素或掩盖细微瑕疵。
- **Clip-path（裁剪路径）** — 将元素裁剪成特定形状，用于揭示、遮罩和前后对比滑块。
- **Mask（遮罩）** — 用形状或渐变隐藏、显露元素的局部——类似 clip-path，但边缘可以柔和、渐隐。
- **Before / after slider（前后对比滑块）** — 可拖动的分隔条，在两幅叠加图片之间擦除切换，以便比较。
- **Line drawing（线条绘制）** — SVG 路径像被一支看不见的笔逐步描出来一样自行绘制。
- **Text morph（文字形变）** — 文本发生变化时逐字符动画，吸引用户注意新的值。
- **Skeleton / Shimmer（骨架屏／闪光）** — 内容加载期间显示的占位内容，带有移动的光泽。
- **Number ticker（数字滚动器）** — 数字滚动或递增到某个值。
- **Tabular numbers（等宽数字）** — 使用固定宽度的数字，使数字变化时不会左右跳动。对滚动器、计时器和计数器必不可少。
- **Typewriter（打字机）** — 文本像被逐字输入一样，一次出现一个字符。

### 性能 — 让运动保持流畅而不卡顿的因素

- **Frame rate (FPS)（帧率）** — 每秒绘制的帧数。60fps 是流畅运动的基础；较新的显示器可达到 120fps。
- **Jank（卡顿）** — 浏览器无法跟上动画而掉帧时出现的可见停顿。
- **Dropped frame（丢帧）** — 浏览器错过某帧的绘制期限，导致运动出现细小顿挫。
- **Compositing（合成）** — 让 GPU 在独立图层上移动或淡化元素，而不重新执行布局或绘制。
- **will-change** — CSS 提示，告知浏览器某元素即将动画，以便提前将其提升到独立图层。
- **Layout thrashing（布局抖动）** — 为 width、height、top 或 left 等属性添加动画，迫使浏览器每帧重新计算布局，造成卡顿。

### 应掌握的原则 — 指导何时以及如何添加动画的概念

- **Purposeful animation（有目的的动画）** — 运动应服务于功能——帮助定位、提供反馈、展示关系——而不只是装饰。
- **Anticipation（预备动作）** — 在主要动作前先朝相反方向稍微蓄力，暗示即将发生什么。
- **Follow-through（跟随动作）** — 主要运动停止后，元素的局部仍继续移动并略微沉降，增加重量感。
- **Squash & stretch（挤压与拉伸）** — 元素运动时发生形变，以传达重量、速度和柔韧性。
- **Perceived performance（感知性能）** — 恰当的动画会让界面感觉更快，即使实际速度没有变化。
- **Frequency of use（使用频率）** — 用户越常看到某个动画，该动画就应越短、越细微。
- **Spatial consistency（空间一致性）** — 通过动画让元素在不同状态间保持身份和位置，使用户始终知道内容去了哪里。
- **Hardware acceleration（硬件加速）** — 为 transform 和 opacity 添加动画，可让 GPU 保持运动流畅。
- **Reduced motion（减少动态效果）** — 尊重用户的 prefers-reduced-motion 设置，减弱或移除运动。
