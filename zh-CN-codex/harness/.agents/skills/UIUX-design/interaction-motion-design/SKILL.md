# 交互与动效设计

在已有界面设计与用户需求的范围内，设计清晰、及时、可使用的交互；动效应帮助理解状态或空间关系。遵循 UIdesign 角色的提问和等待答复规则，不以本技能替代用户决定。

## 工作方法

1. 确认目标平台、主要操作、使用频率和用户对动效的偏好；缺少影响方案的关键条件时向用户询问。
2. 对每个关键交互说明触发方式、状态变化、反馈、结果及异常或取消方式。先保证操作和反馈清楚，再决定是否需要动效。
3. 动效应有明确作用，例如提示状态、建立空间关系或缓和突变。高频操作和快捷键优先即时响应；没有明确作用的动效可以省略。
4. 弹出内容的出现方向应体现与触发控件的关系；连续或重复操作时，过渡应能及时响应新输入。时长、缓动与运动幅度按场景和平台调试，不将固定数值视为通用标准。
5. 兼顾键盘、焦点、触摸或指针等适用输入方式，并尊重系统或产品的减少动态效果设置；减少位移时仍保留必要的状态反馈。颜色不应成为状态的唯一提示。
6. 交接时列出交互状态、必要动效及其目的、减少动态效果方案和待验证事项。使用实际平台工具进行视觉和交互验证；无法验证时明确说明。

## 审查重点

检查反馈是否及时、频繁操作是否被动画拖慢、弹层与触发源是否关联、快速重复操作是否响应、键盘和减少动态效果是否可用，以及目标设备上是否流畅。优先删除或减弱无必要动效，再调整细节。
