# 执行计划

active 保存待确认及进行中计划，completed 保存已完成或已取消的归档计划。复杂任务使用模板，已选择直接修改的功能任务无需新建计划。

用户选择功能设计规划后调用 [feature-plan](../../.agents/skills/feature-plan/SKILL.md)，由主 agent 逐题访谈、同步整理 specs 中的规格书，自动分配 PLAN-0001 形式的共用编号，再生成详细功能清单。规格书与计划各有版本，一起展示确认；部分回答不代表整体批准。待确认计划也保存在 active，确认后在同一文件跟踪执行；完成后移至 completed。取消的计划注明取消再归档，不视为实现完成。规格书保留在 specs，归档时更新双向引用。

每个项目独立编号；修订和续接沿用原计划，受影响文档实质变更递增版本并重新确认组合。实现清单项使用 PLAN-0001.01 形式的稳定编号，并引用规格书验收编号。批准依据、逐项简报、报告摘要、审查和恢复位置集中保存在原计划，不另建重复进度记录。
