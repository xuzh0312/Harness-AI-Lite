# UI Technique Atlas

Keep the extracted files together. Open the [Layout Atlas](<布局图鉴.html>) or the [Motion and Materials Atlas](<动效与材质图鉴.html>) directly in a modern browser. No installation, build step, or server is required.

- Each start page compares techniques that are easy to confuse. Select **Browse all entries** to open the catalog. Browse by chapter, or search by entry number or English term.
- A **Comparison** link jumps to a matching example above the catalog. Other examples start when you expand their entries and reset when you collapse them. In the Layout Atlas, **Wide container** and **Narrow container** affect both the comparisons and the catalog previews.
- Each example shows the source that produces its preview. An **Approximation** recreates selected characteristics. An **Illustration** explains the idea without claiming that a native system, device, or model is integrated.
- For agents: find an example by term, compare before and after or wide and narrow states, then inspect the source. Reuse only the mechanism that makes the example work, not its copy or palette.

Coverage: the [layout taxonomy](<页面布局设计全景分类参考.md>) has 48 numbered entries and the [motion and style taxonomy](<动效界面设计风格全景分类参考.md>) has 68. The taxonomies overlap, so 116 entries does not mean 116 distinct techniques. Resource tables and technical appendices do not have separate demos.
