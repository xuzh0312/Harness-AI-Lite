06 / RELIEF

Neumorphism

1.1 · 1.3

The background and controls are identical; only the pair of shadows changes. Outer shadows make a control look raised; inset shadows make it look recessed. Do not rely on shadows alone to indicate state.

Shadow swatches / light from the upper left

These controls demonstrate appearance only. Keep dark text, a border, and a distinct focus ring: soft shadows alone do not provide enough contrast.

09 / COLOR

Aurora vs. Mesh Gradient

2.1 · 2.2

The same label sits on each background. Aurora gradients often use soft diagonal bands of light, while mesh gradients smoothly blend several color points. The effects can overlap; this comparison shows visual conventions, not a strict mathematical distinction.

Background swatches / all static

The aurora uses CSS to layer and blur two bands of light. The simplified SVG mesh interpolates two rows of color points horizontally, then blends the rows vertically.
