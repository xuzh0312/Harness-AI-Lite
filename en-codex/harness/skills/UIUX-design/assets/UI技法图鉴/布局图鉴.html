02

Equal-Width Grid vs. Bento Layout

Layout reference §1.8 and §1.11

An equal-width grid gives items similar visual weight. A bento layout keeps the grid alignment but lets Trail Overview span columns and rows. On narrow screens, it still spans columns, but only occupies one row.

06

Row-Aligned Grid vs. Masonry

Layout reference §1.8 and §1.10

Both layouts use the same six cards of varying heights. In a row-aligned grid, the tallest card sets the row height, leaving gaps below shorter cards. Masonry stacks cards continuously in each column. This example approximates masonry with CSS columns: read down each column rather than expecting each card to fill the shortest one.

07

Top Navigation vs. Bottom Tab Bar

Layout reference §3.1 and §3.2

The three primary destinations stay the same; only the navigation moves. Top navigation fits a top-to-bottom scan, while a bottom tab bar is easier to reach with your thumb on a phone. This demo shows placement only, not fixed positioning or page changes.

12-Column Grid: Equal vs. Weighted Spans

Layout reference §7.1 and §7.3
