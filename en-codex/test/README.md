# Development and test materials

Store code and development materials that are outside the software implementation here. This includes test code and data, reproduction and verification scripts, mock services, build and packaging helper scripts, project design drafts, interactive prototypes, temporary experiments, raw logs, screenshots and recordings, caches, intermediate artifacts, and output other than installers. Organize this area according to the project's actual needs without setting up a technology stack in advance.

When running tests, specify the actual paths of the software code and this directory, and record the code version. Keep brief task and bug records in `harness`. For final ZIP delivery, follow the packaging authorization and location rules in `harness/ARCHITECTURE.md`. Report conflicts first if a tool cannot comply with the directory requirements.
