# Development and Test Materials

Holds all non-product code and development material: test code and data, reproduction and validation scripts, mock services, build/packaging helper scripts, temporary experiments, raw logs, screenshots and recordings, cache, intermediate artifacts, and non-installer output. Organize by actual project needs; do not pre-build a tech stack.

When running tests, state the actual paths of the software code and this directory and associate them with the code version. Keep brief task and defect records in harness; final installer packages go in project/installpark only after explicit packaging. Report conflicts first when a tool cannot follow the directory requirement.
